Security Controls
Production account adjustments require additional controls.
Administrator Authentication
Only authenticated administrators with the required permission should be able to create adjustments.
Audit Logging
Every adjustment must generate an immutable audit record containing who performed it, what changed, why it changed, and when it happened.
Authorization
