Admin Settings

Configure NovaVest platform preferences and controls.

Some controls are not active yet. Registration, KYC, transaction, notification, session, maintenance, currency, and contact controls below are currently display-only and do not change the live backend. The announcement and platform-mode controls are the only settings connected to the secure settings function. Do not rely on inactive switches to enforce financial or security rules.

Platform Settings (display only)

Basic configuration for the NovaVest platform.

Registration

Control how new accounts can be created.

Allow New Registrations Allow visitors to create new accounts.
Email Verification Require users to verify their email address.
Referral Registration Allow users to register through referral links.

KYC & Verification

Configure identity verification requirements.

Require KYC Before Withdrawal Users must complete verification before withdrawals.
Require Government ID Require an accepted government identification document.
Require Passport Allow passport verification as an additional document.

Transaction Controls

Configure how financial requests are handled. These controls are inactive display-only switches; no backend enforcement is connected.

Allow Deposits Allow users to submit deposit requests.
Allow Withdrawals Allow users to submit withdrawal requests.
Manual Transaction Review Require administrator review before processing requests.

Notification Defaults

Default communication preferences for legitimate account events.

Email Notifications Send important account notifications by email.
Transaction Alerts Notify users about their actual transaction events.
Security Alerts Notify users about login and security events.

Security & Sessions

Recommended security controls for the administrator area.

Two-Factor Authentication Require additional authentication for administrators.
Audit Logging Record administrator actions for security review.
Automatic Session Expiration Expire inactive administrator sessions.

Support & Contact

Contact information displayed to platform users.

Maintenance Mode

Temporarily restrict access while maintenance is being performed.

Maintenance Mode When enabled, regular users should see a maintenance message.
⚠️ Maintenance mode should only be enabled when necessary. This switch is display-only and does not activate maintenance mode.

Platform Announcement

Create a general informational message that can later be displayed to authenticated users.

Settings saved to the secure platform backend.

Danger Zone

Destructive actions should require backend authorization and additional confirmation in production.

⚠️ This frontend cannot securely change production platform settings. Once the backend is connected, every sensitive action must require authenticated administrator authorization and an audit log.
